## 接续证据与限制

- 批次 009 固定参考证明：未创建自身 HWND 的 Control 保留负尺寸；有 HWND 时负数归零，实际零宽高可恢复。首次创建将原值交给 USER32 后回读实际矩形，int.MinValue 宽度涉及 CW_USEDEFAULT，不能预先统一钳制；派生原生高度扩展不能写回正逻辑高度。Form.ScaleSize 的最小 1 与完整缩放/派生限制仍另列。
- 三个 typed AddRange 均拒绝 null 数组（参数 items），均跳过 null 元素；文本 null 元素与单项 Add(null) 的归空行为不同。非 null 的空 Text 子项仍应添加。空数组不创建首项；对象身份、输入槽复制、重复/其他 owner、借用 Font、共享数据与独立最后 key 索引继续保留。
- 焦点仍使用真实 HWND 状态，无自身 HWND 查询/Focus 不创建句柄。禁用原生父窗口时 CanFocus 可为 true 而实际 Focus 为 false，不能用托管标志改写。旧同步/异步投递、显式/default context 继续回归。
- ApplicationContext/多 UI/模态/关闭/重建竞态、Form 全局 OpenForms 退出与完整 Select/键盘事件仍未关闭。保留 Demo 原始静态 Designer/resx；复杂 UI/设备/压力/设计器集中后置，先 Windows 后 Linux，macOS 单列。代码完成与完整兼容验收分开，不从任务或编译数量推算 98%，不用空方法、吞异常或常量成功代替行为。
