## 接续证据与限制

- 批次 011 的标准通知链为 OnLocationChanged → OnMove/Move → LocationChanged、OnSizeChanged → OnResize/Resize → SizeChanged。OnLocationChanged 向 OnMove 透传参数，OnSizeChanged 向 OnResize 传 EventArgs.Empty，SizeChanged 保留原参数。位置和尺寸变化先快照，整矩形先提交；旧 OnBoundsChanged 仍独立衔接派生布局，旧派生不调用 base 也不跳过标准通知。
- 外框标准通知链在有自身 HWND 时将原异常交给现有 Application.ThreadException，无自身 HWND 或直接 protected On* 同步传播；SetClientSizeCore 末尾直接发出的 ClientSizeChanged 原异常仍同步传播，包括同值 ClientSize 赋值。完整异常模式与关闭/重建竞态仍未关闭；不要将此扩为新的异常架构。
- 批次 010 指定边界 2,034 条、批次 009 尺寸 756 条固定参考/JIT/实际 AOT 已取证；未知 specified 原样传递、外层保留未指定分量、core 接完整矩形、重复不重复通知。首次创建仍交原参数给 USER32 再回读；GetNativeHeight 的正逻辑高度不能被原生扩展值覆盖。
- 批次 011 子项接口固定参考/JIT 的 1,406 条已相同。ICollection.CopyTo 为 private 显式成员（dest/index），保留历史 typed CopyTo；空集合不验证错误数组也不恢复首项。非空按 rank/index/容量/类型顺序并保留派生数组失败前写入。IList.Add 重复对象返回首次引用位置，类型校验先于位置；各 view SyncRoot 为自身、IsSynchronized 按参考为 true，不代表完整并发已验收。查询与移除均按引用身份，key 缓存各 view 独立。
