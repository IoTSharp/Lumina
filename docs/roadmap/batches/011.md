## 接续证据与限制

- 批次 010 的 BoundsSpecified 八个标准值/Flags、x/y 命名两族 SetBounds 与 protected virtual SetBoundsCore 已接通，2,034 条固定参考/JIT/实际 AOT 相同。外层按已知位保留其他分量、未知位原样传递、有效矩形未变不调用 core；直接 core 接完整矩形，即使 specified=None 或由派生调整未指定分量。通知工作必须保留这些轨迹。
- 批次 009 尺寸 756 条三端对照继续通过。无自身 HWND 保留负尺寸且不创建，有 HWND 负数归零、零宽高可恢复；首次创建将原始尺寸交给 USER32，再在 HandleCreated 前回读，int.MinValue 宽度涉及 CW_USEDEFAULT。GetNativeHeight 的正逻辑高度不改成原生扩展高度。
- typed Insert 先 index 后 item；公开 Remove 为非虚 void，按引用身份只删首个，null/缺失无操作。203 条固定参考/JIT 相同，泛型 bool Remove 和 Insert 显式适配保留。Clear/RemoveAt 为 CLR 接口 virtual-final；各视图共享数据但最后 key 索引独立，Clear/变更不主动清缓存。现 typed Contains/IndexOf 仍委托 List<T>，不能把其行为作为新接口参考。
- 保留组件/旧投递、Action/旧 Task/ValueTask、显式/default context、焦点、原尺寸和子项构造/样式/key/集合/Add/AddRange 回归。ApplicationContext/多 UI/模态/关闭/重建竞态、Form 进程全局 OpenForms 退出与完整 Select/键盘事件仍未关闭。
- 保留原始静态 Designer/resx。复杂 UI/设备/压力/设计器集中后置，先 Windows 后 Linux，macOS 单列。明确范围代码完成与完整兼容验收分开，不从任务或编译数量推算 98%，不用空方法、吞异常或常量成功代替行为。
