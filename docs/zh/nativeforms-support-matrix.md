# LuminaForms 支持状态入口

更新：2026-11-07。**当前实施状态统一维护在[逐控件与公共任务索引](../roadmap/README.md)。** 原 2026-10-15 支持矩阵是历史评估快照，关于 Form 层级、RichEdit 后端、线程投递和分析器分发的部分描述已被后续批次改变；本页不再维护另一份状态表。

| 要确认的内容 | 对应入口 |
| --- | --- |
| 控件是否完整、哪些范围已完成/仍未完成 | [任务索引](../roadmap/README.md)，对应任务页的当前表与修改历史 |
| 共有线程、继承、生命周期、布局、输入、资源问题 | [公共基础](../roadmap/foundations.md)与[附属契约](../roadmap/contracts.md) |
| Windows、Linux、macOS 是否通过真实验收 | [验证门槛](../roadmap/validation.md)与[平台进入条件](../roadmap/platforms.md) |
| 成员、接口与固定分母 | [API 基线](../roadmap/api/baseline.json)与[98% 计量](../roadmap/coverage.md) |
| 某批改动与原始失败/诊断 | [001～069 批次索引](../roadmap/batches/README.md) |
| 迁移方法和待处理差异 | [迁移指南](nativeforms-migration.md)与[兼容导航](nativeforms-compatibility.md) |

代码完成子范围不等于完整控件完成，同名类型不等于支持，历史探针/AOT 发布不等于当前整产品运行验收。当前没有完整逐项证据可宣布达到 98%。
